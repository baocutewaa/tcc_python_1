1.1 Bản Chất Máy Tính & Biểu Diễn Số Trong Bộ Nhớ

Lưu Trữ Dữ Liệu Bằng Bits & Bytes

  • Máy tính lưu trữ thông tin dưới dạng các dãy Bit (0 và 1).
  • Với 3 bits: Có $2^3 = 8$ trạng thái (từ 000 đến 111). Biểu diễn được số nguyên dương ($0..7$), số âm ($-1..-8$), hoặc hỗn hợp ($-3..4$).
  • Với 8 bits (1 Byte): Có $2^8 = 256$ trạng thái:
    • unsigned char: Số nguyên không dấu ($0$ đến $255$).
    • char (Signed): Số nguyên có dấu ($-128$ đến $127$).
  • Số thực Floating-Point:
    • float ($4 \text{ bytes} = 32 \text{ bits}$): Độ chính xác đơn.
    • double ($8 \text{ bytes} = 64 \text{ bits}$): Độ chính xác kép.
PYTHON / C CONCEPT

# Python tự động quản lý kiểu dữ liệu bộ nhớ

pi_val = 3.14       # Float 32-bit/64-bit representation
e_val = 2.71828     # Double precision float

print("Giá trị a_number:", a_number)
print("Giá trị pi_val:", pi_val)
print("Giá trị e_val:", e_val)
OUTPUT:
Giá trị a_number: 6 Giá trị pi_val: 3.14 Giá trị e_val: 2.71828

1.2 Bảng Mã ASCII & So Sánh C++ vs Python

Lưu Trữ Văn Bản & So Sánh C++ / Python

  • Bảng mã ASCII: Mã hóa 128 kí tự tiêu chuẩn thành các số 8-bit (Byte). Ví dụ: Kí tự 'A' có mã Decimal 65 (01000001).
  • C++: Ngôn ngữ biên dịch (Compiled), tĩnh (Statically Typed), quản lý bộ nhớ thủ công, cú pháp dài.
  • Python: Ngôn ngữ thông dịch (Interpreted), động (Dynamically Typed), cú pháp cực kỳ tinh gọn, giàu thư viện AI/Data Science.
  • Hệ sinh thái Python: Đứng Top 1 ngôn ngữ phổ biến theo IEEE Spectrum & TIOBE Index.
C++ VS PYTHON

3.3 Built-in Functions, Ép Kiểu & Các Hàm math / random

Hàm Dựng Sẵn & Thư Viện Toán Học / Xác Suất

  • Hàm tích hợp (Built-in): print(), type(), input(), round(), abs().

3.3 Bài Toán Thực Tế: Chuyển Đổi Nhiệt Độ & Hình Học

Công Thức Tính Toán Thực Tế

$$F = \frac{9}{5}C + 32 \quad \Longleftrightarrow \quad C = (F - 32) \times \frac{5}{9}$$
  • Chuyển đổi nhiệt độ: Đổi Celsius sang Fahrenheit và ngược lại.
  • Chu vi & Diện tích hình chữ nhật:
    $$\text{Perimeter} = 2 \times (h + w), \quad \text{Area} = h \times w$$
  • Chu vi & Diện tích hình tròn:
    $$\text{Perimeter} = 2 \pi r, \quad \text{Area} = \pi r^2$$
PYTHON CODE 
import math

# 1. Chuyển đổi Celsius -> Fahrenheit
celsius = 30.0
fahrenheit = (9/5) * celsius + 32
print(f"{celsius}°C = {fahrenheit}°F")

# 2. Chuyển đổi Fahrenheit -> Celsius
f_in = 86.0
c_out = (f_in - 32) * (5/9)
print(f"{f_in}°F = {c_out}°C")

# 3. Tính diện tích hình tròn r = 5.0
radius = 5.0
circle_area = math.pi * (radius ** 2)
print(f"Diện tích hình tròn r={radius}: {circle_area:.4f}")
OUTPUT:
30.0°C = 86.0°F 86.0°F = 30.0°C Diện tích hình tròn r=5.0: 78.5398

4.2 Bài Toán Xấp Xỉ Chu Vi & Diện Tích Đường Tròn Đơn Vị

Mô Hình Chia Nhỏ $m$ Đoạn (Polygon Approximation)

$$\alpha = \frac{2\pi}{m}, \quad L = m \times \sin(\alpha), \quad A = m \times \frac{\sin(\alpha)\cos(\alpha)}{2}$$
  • Khi chia đường tròn đơn vị ($r=1$) thành $m$ đoạn tam giác cân:
    • Góc ở tâm của mỗi phân đoạn là $\alpha = \frac{2\pi}{m}$.
    • Độ dài chu vi xấp xỉ $L = m \cdot \sin(\alpha)$.
    • Diện tích xấp xỉ $A = m \cdot A_{\alpha} = m \cdot \frac{\sin(\alpha)\cos(\alpha)}{2}$.
  • Khi $m \to \infty$, giá trị $L \to 2\pi \approx 6.28318$ và $A \to \pi \approx 3.14159$.
PYTHON CODE 
import math

def compute_unit_circle_perimeter(m):
    alpha = (2 * math.pi) / m
    return m * math.sin(alpha)

def compute_unit_circle_area(m):
    alpha = (2 * math.pi) / m
    area_triangle = (math.sin(alpha) * math.cos(alpha)) / 2
    return m * area_triangle

print("Chu vi xấp xỉ (m=10):", compute_unit_circle_perimeter(10))
print("Chu vi xấp xỉ (m=1000):", compute_unit_circle_perimeter(1000))
print("Diện tích xấp xỉ (m=10):", compute_unit_circle_area(10))
print("Diện tích xấp xỉ (m=10000):", compute_unit_circle_area(10000))
OUTPUT:
Chu vi xấp xỉ (m=10): 5.877852522924731 Chu vi xấp xỉ (m=1000): 6.283145388277259 Diện tích xấp xỉ (m=10): 2.938926261462366 Diện tích xấp xỉ (m=10000): 3.1415925307436034

4.3 Ứng Dụng Đạo Hàm Số Học (Numerical Derivative)

Công Thức Đạo Hàm Một Bên Trong Máy Tính

$$f'(x) = \lim_{\Delta x \to 0} \frac{f(x + \Delta x) - f(x)}{\Delta x}$$
  • Xét hàm số $f(x) = x^2 + 2x$, đạo hàm lý thuyết $f'(x) = 2x + 2$. Tại $x = 3 \implies f'(3) = 8$.
  • Trên máy tính, ta chọn $\Delta x$ (epsilon) rất nhỏ (ví dụ $10^{-5}$) để xấp xỉ đạo hàm tại điểm $x$.
  • Theo lý thuyết, $\Delta x$ càng nhỏ thì giá trị đạo hàm càng chính xác!
PYTHON CODE 
def f(x):
    return x**2 + 2*x

def compute_derivative(x, delta_x=1e-5):
    '''Tính đạo hàm số học một bên f'(x)'''
    return (f(x + delta_x) - f(x)) / delta_x

x_val = 3
approx_diff = compute_derivative(x_val)
exact_diff = 2 * x_val + 2

print(f"Giá trị đạo hàm lý thuyết f'({x_val}) = {exact_diff}")
print(f"Giá trị đạo hàm số học f'({x_val})  = {approx_diff:.6f}")
print(f"Sai số tuyệt đối: {abs(approx_diff - exact_diff):.8f}")
OUTPUT:
Giá trị đạo hàm lý thuyết f'(3) = 8 Giá trị đạo hàm số học f'(3) = 8.000010 Sai số tuyệt đối: 0.00001000

5.1 Cấu Trúc Điều Kiện & Hàm Kích Hoạt ReLU

Cú Pháp If-Else & Ứng Dụng Trong Deep Learning

  • Toán tử so sánh: == (bằng), != (khác), >, <, >=, <=.
  • Cấu trúc: if condition: ... elif condition: ... else: ...
  • Hàm kích hoạt ReLU (Rectified Linear Unit):
    $$\text{ReLU}(x) = \begin{cases} 0 & \text{nếu } x \le 0 \\ x & \text{nếu } x > 0 \end{cases}$$
PYTHON CODE 
def relu(x):
    '''Hàm kích hoạt ReLU trong mạng Nơ-ron'''
    if x <= 0:
        return 0
    else:
        return x

print("ReLU(-5.0) =", relu(-5.0))
print("ReLU(0.0)  =", relu(0.0))
print("ReLU(3.14) =", relu(3.14))
OUTPUT:
ReLU(-5.0) = 0 ReLU(0.0) = 0 ReLU(3.14) = 3.14

5.2 Chuyển Đổi If-Else Thành Biểu Thức Toán Học & One-Hot Vector

Kỹ Thuật Toán Học Hóa Điều Kiện Nhánh

  • Nếu $a = 0 \implies y = b^2$; nếu $a = K \implies y = b$:
    $$y = \frac{a}{K} b + \frac{K - a}{K} b^2$$
  • Chuyển biến điều kiện $a \in \{0, 1, 2\}$ thành One-Hot Vector $\mathbf{v}$:
    • $a = 0 \implies \mathbf{v} = [1, 0, 0]$
    • $a = 1 \implies \mathbf{v} = [0, 1, 0]$
    • $a = 2 \implies \mathbf{v} = [0, 0, 1]$
  • Đặt $\mathbf{u} = [b^2, b, b]^T$, ta có $y = \mathbf{v} \cdot \mathbf{u}$.
PYTHON CODE 
def compute_y_if(a, b):
    if a == 0:
        return b**2
    elif a == 1:
        return b
    else:
        return b

def compute_y_onehot(a, b):
    # One-hot encoding vector
    v = [0, 0, 0]
    v[a] = 1
    u = [b**2, b, b]
    # Dot product v . u
    return sum(v[i] * u[i] for i in range(3))

print("If-else (a=0, b=3):", compute_y_if(0, 3))
print("One-hot (a=0, b=3):", compute_y_onehot(0, 3))
OUTPUT:

5.4 Softmax Naive vs Stable Softmax & Hàm Mũ Lãi Suất

Giải Quyết Lỗi Overflow Trong Softmax

$$P_i = \frac{e^{x_i - m}}{\sum_j e^{x_j - m}} \quad \text{với } m = \max(\mathbf{x})$$
  • Khi $x_i$ lớn (như $1000$), $e^{1000}$ gây lỗi Overflow trong Softmax Naive.
  • Stable Softmax: Trừ đi $m = \max(\mathbf{x})$ giúp tất cả phần tử $\le 0 \implies e^{x_i - m} \in (0, 1]$, triệt tiêu tràn số!
  • Hàm Mũ Lãi Suất: Lãi ghép $n$ lần/năm: $A_t = A(1 + \frac{r}{n})^{nt}$. Khi $n \to \infty \implies A_t = A e^{rt}$.
PYTHON CODE 
import math

def softmax_stable(x_list):
    max_x = max(x_list)
    exp_x = [math.exp(x - max_x) for x in x_list]
    sum_exp = sum(exp_x)
    return [e / sum_exp for e in exp_x]

x = [1.0, 2.0, 3.0]
x_large = [1000.0, 1001.0, 1002.0]

print("Softmax [1, 2, 3]:", [round(p, 4) for p in softmax_stable(x)])
print("Stable Softmax x lớn:", [round(p, 4) for p in softmax_stable(x_large)])

PYTHON CODE 
def pi_gregory_leibniz(n):
    pi = 0
    for i in range(1, n + 1):
        pi += ((-1)**(i + 1)) / (2*i - 1)
    return 4 * pi

def pi_nilakantha(n):
    pi = 3.0
    for i in range(n):
        term = ((-1)**i) * 4 / ((2*i + 2) * (2*i + 3) * (2*i + 4))
        pi += term
    return pi

6.3 Ước Tính Số Euler $e$ & Thuật Toán Căn Bậc 2 Newton-Raphson

Thuật Toán Newton-Raphson Tính $\sqrt{N}$

$$x_{n+1} = \frac{x_n + \frac{N}{x_n}}{2} \quad \text{với } x_0 = \frac{N}{2}$$
  • Ví dụ tìm $\sqrt{9}$: Với $x_0 = 4.5 \implies x_1 = 3.25 \implies x_2 = 3.009 \implies x_3 = 3.00001$. Hội tụ cực kỳ nhanh!
  • Số $e$ được tính qua tổng giai thừa $e = \sum_{k=0}^n \frac{1}{k!}$.
PYTHON CODE 
def compute_sqrt_newton(N, num_iterations=4):
    x = N / 2.0
    for i in range(num_iterations):
        x = (x + N / x) / 2.0
        print(f"Lần lặp {i+1}: x = {x:.5f}")
    return x

print("Tính căn bậc 2 của N=9:")

10.1 Khái Niệm Đệ Quy & Mô Phỏng Monte Carlo Ước Tính PI

Mô Phỏng Xác Suất Hình Học Monte Carlo

$$\frac{A_{circle}}{A_{square}} = \frac{\pi r^2}{s^2} = \frac{\pi (1)^2}{2^2} = \frac{\pi}{4} \approx \frac{N_c}{N_s} \implies \pi \approx 4 \times \frac{N_c}{N_s}$$
  • Sinh $N_s$ điểm ngẫu nhiên $(x, y) \in [-1, 1] \times [-1, 1]$.
  • Đếm số điểm $N_c$ nằm bên trong đường tròn ($x^2 + y^2 \le 1$).
PYTHON CODE 
import random

def pi_monte_carlo(num_samples):
    inside_circle = 0
    for _ in range(num_samples):
        x = random.uniform(-1, 1)
        y = random.uniform(-1, 1)
        if x**2 + y**2 <= 1:
            inside_circle += 1
    return 4 * inside_circle / num_samples

print("Monte Carlo PI (10,000 mẫu): ", pi_monte_carlo(10000))
print("Monte Carlo PI (100,000 mẫu):", pi_monte_carlo(100000))
OUTPUT:
Monte Carlo PI (10,000 mẫu): 3.1416 Monte Carlo PI (100,000 mẫu): 3.14144

PYTHON CODE 
def fibonacci(n):
    seq = [0, 1]
    while len(seq) < n:
        seq.append(seq[-1] + seq[-2])
    return seq[:n]

def pascal_triangle(levels):
    triangle = []
    for i in range(levels):
        row = [1] * (i + 1)
        for j in range(1, i):
            row[j] = triangle[i-1][j-1] + triangle[i-1][j]
        triangle.append(row)
    return triangle

print("Fibonacci (9 phần tử):", fibonacci(9))
print("Pascal Triangle (5 tầng):")
for row in pascal_triangle(5):
    print(row)

10.3 Chuỗi Taylor Xấp Xỉ Các Hàm Lượng Giác & Mũ

Khai Triển Taylor Lượng Giác & Hàm Mũ

$$\sin(x) = \sum_{n=0}^{\infty} \frac{(-1)^n x^{2n+1}}{(2n+1)!} = x - \frac{x^3}{3!} + \frac{x^5}{5!} - \dots$$
$$\cos(x) = \sum_{n=0}^{\infty} \frac{(-1)^n x^{2n}}{(2n)!} = 1 - \frac{x^2}{2!} + \frac{x^4}{4!} - \dots$$
$$e^x = \sum_{n=0}^{\infty} \frac{x^n}{n!} = 1 + x + \frac{x^2}{2!} + \frac{x^3}{3!} + \dots$$
PYTHON CODE 
import math

def sin_taylor(x, terms=10):
    val = 0
    for n in range(terms):
        val += (((-1)**n) / math.factorial(2*n + 1)) * (x**(2*n + 1))
    return val

def exp_taylor(x, terms=15):
    return sum((x**n) / math.factorial(n) for n in range(terms))

x_rad = math.pi / 6 # 30 độ -> sin = 0.5
print("sin(pi/6) Taylor: ", sin_taylor(x_rad))
print("sin(pi/6) Math library:", math.sin(x_rad))
print("e^1.0 Taylor:     ", exp_taylor(1.0))

  • index() văng lỗi ngoại lệ ValueError.

Câu Hỏi 3: Tại sao nên dùng từ khóa with khi thao tác mở Tệp (File Handling)?
